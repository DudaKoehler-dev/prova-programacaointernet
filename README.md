# Calculadora de IMC

Aplicação em Flask que calcula o IMC a partir de nome, peso e altura e mostra a faixa do resultado.

Disciplina: Programação para Internet (ILP951) - Fatec Jahu

## Como rodar

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Abrir http://127.0.0.1:5000 no navegador.

## Rotas

- `/` calculadora de IMC
- `/equipe` dados da equipe
